# 150K Combine Tracker

- The app source is `150K Combine tracker.html`. Make all edits there.
- `index.html` is a copy of that file. When you change the tracker file, also copy it over
  (`cp "150K Combine tracker.html" index.html`) in the same commit. The
  `.github/workflows/sync-index.yml` workflow does the same copy on every push as a backstop.
